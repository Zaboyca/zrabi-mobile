App Review Notes — zrabi (by.zrabi.zrabi)

PURPOSE / AUDIENCE
zrabi.by is a marketplace for local services in Belarus. Clients post orders; specialists browse open orders, respond, chat, and complete jobs. Target audience: clients and independent service providers (home repair, beauty, tutoring, auto, etc.).

DEVICES / OS TESTED
- iPhone (physical device “Anastas”), iOS current stable
- Built with Xcode + Flutter release

CORE FLOWS TO REVIEW
1) Launch app → Home (categories, specialists, create order).
2) Sign in with the demo account above.
3) Create order (or open an existing order) → specialist response / chat if available.
4) Account deletion (Guideline 5.1.1): Profile → “Удалить аккаунт” → enter password → confirm.
   Success message: “Ваш аккаунт был успешно удалён”.
   After deletion the session ends and the guest home is shown.
